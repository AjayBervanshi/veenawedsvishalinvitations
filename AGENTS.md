# Agent Rules & Workflow

## Core Execution Rule
Always follow this strict sequential workflow on every request:
1. **Analyse**: Thoroughly analyze the requirements, inspect relevant code, identify root causes and constraints.
2. **Create Todo**: Formulate an explicit, structured, and prioritized TODO checklist before making any code modifications.
3. **Then Proceed**: Execute the tasks step-by-step, verify visually and programmatically with tests.
